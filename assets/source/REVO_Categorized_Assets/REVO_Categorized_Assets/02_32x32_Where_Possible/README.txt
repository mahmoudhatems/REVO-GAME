REVO assets - 02_32x32_Where_Possible

Assets are grouped into category folders (Astronaut, Tools_Equipment, Floor_Tiles, etc.).
Each filename follows Category_Number_WidthxHeight.png.
Example: Door_001_32x55.png
The name and dimensions are part of the filename, not printed over the artwork.

Assets that fit within 32x32 are centered on a transparent 32x32 canvas without scaling. Assets larger than 32px in either dimension retain their native dimensions to protect details.
Transparent backgrounds are preserved.
Asset_Manifest.csv lists exact file dimensions, artwork dimensions, source sheet and crop coordinates.
